# Titanic-SQL-analysis
SQL analysis of the titanic dataset using MySQL workbench 

### About Project
Analyzed Titanic passenger data to find survival patterns based on gender, age, and passenger class.

### Tools Used
- MySQL Workbench
- SQL - SELECT, WHERE, GROUP BY, JOIN, AVG, COUNT

### Dataset
- `train.csv` - Titanic passenger data (891 rows)

### Key Queries
- Total passengers, survival rate
- Survival rate by gender and class
- Average age of passengers
- Passenger details

### Queries File
All queries are in `Titanic-queries.sql`
